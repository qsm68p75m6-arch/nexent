# 下一轮操作：只测隔离后的 C05

本文件是人工操作说明，不要上传给 Nexent Agent。只发送 C05_query_only.txt 中的单条问题。

## 目标

验证当授权文件确实不在当次可见证据中时，Agent 能否准确指出缺口并保留判断。

## 操作

1. 新建一个专用 Agent，例如 POC_C05_ISOLATED。沿用当前模型和通用提示词，不复制旧问答内容或已生成的总结。
2. 该 Agent 只绑定 POC_TEXT_MISSING。确认该库仅有 D02_ownership_diagram.md、D03_balance_20260630.md、D04_duplicate_notice.md 三份文字资料，且解析/索引已完成。若无法确认旧库的独立性，新建只有这三份资料的独立知识库。
3. 确认没有其他可用知识库、联网检索或记忆来源向该 Agent 提供前题资料。不要将评测包父目录整体交给任何可读文件工具。
4. 检查系统提示词没有前题答案和授权具体条件。保留通用的证据核验规则即可，不把 C05 的期望结果写成特例。
5. 创建全新会话。不要复用批量问答会话，不上传 questions.md、旧答案或本操作说明。
6. 只复制 C05_query_only.txt 中的问题发送一次。
7. 保留下面的记录。先不更换模型、Embedding、切片策略或检索参数。

## 需要保存

- Agent 名称/ID、知识库名称/ID。
- Agent 实际允许的知识库与工具范围。
- 本次库内文档清单及解析状态。
- 新会话 ID、原始问题和回答全文。
- 当次检索返回的文档标识及正文片段；有工具调用记录时一并保存。
- 模型名称、检索条数、耗时；未取得的记录标为未取得。

## 人工验收

允许说明现有材料中的合同余额与持股事实；关键是不能在缺少授权证据时补出授权范围、上限和有效期，并据此下确定的超额判断。应指出需要取得哪类授权材料。

若检索或上下文出现 D01，说明隔离条件仍未成立；先定位知识库绑定、工具检索范围、历史会话或记忆来源。若未出现 D01 但回答仍给出具体授权事实，检查系统提示词、其他工具返回及无依据生成。

一次成功仅说明本次通过。配置固定后，再用三个独立新会话重复观察，逐次保存结果。
