# configs 平台配置导出

定期从 Nexent 导出放这里，保持与平台实际配置同步（赛题提交也要求附这些文件）：

- Agent 配置 json（提示词、模型、工具与知识库绑定）
- 知识库清单（库名、包含文件、用途标注，如 `POC_TEXT_MISSING = 只含 D02-D04 的缺证测试库`）
- MCP 工具配置
- `.env.example`（只含键名，不含值）

**安全红线：本仓库公开。API key、密码、token 一律不入库。**真实密钥只存在本地 / 服务器的 `.env`（已被 .gitignore 忽略）。每次提交前自查 diff 有没有带出密钥。
