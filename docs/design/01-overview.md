## 已确认

- **赛题**：基于华为 ModelEngine Nexent 打造可进化决策智能体（赛题3）。初赛技术评分四项各占 25%（智能体编排与 MCP/Skill 深度集成、资产激活的业务价值验证、算法创新性、系统交互体验与能力沉淀）；总决赛技术评分 60% + 答辩 40%，附加分：多行业模板轻量化迁移适配验证、真实脱敏行业数据集效果评测。
- **业务场景（已定）**：金融——上市公司对外担保披露核验。目标用户：研究员、审计、合规人员。系统接收一组公开披露文件，整理待复核担保事项，逐条给出带证据的核验结论。
- **选场景的理由**（2026-10-22 讨论定）：无行业数据的条件下，公开资料能凑出较完整的证据链（担保公告、财务附注、授权决议、补充公告）；场景天然包含文本、表格、关系图与跨文档推理；需要区分"授权额度 / 实际发生额 / 期末余额"等口径，能充分展示决策溯源。
- **示例业务问题**："截至某日，该公司已披露的担保余额是否落在当时有效的授权范围内？"
- **迁移备选场景**：政务项目申报预审（呼应附加分"多行业模板轻量化迁移"）。
