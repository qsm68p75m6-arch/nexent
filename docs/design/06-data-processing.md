# 06 数据处理说明

## 已确认

- 解析链路：PDF → 文本 / 表格 → 切片 → 检索索引；股权关系图以图像嵌入 PDF（图片轮待验证图像是否真正参与判断，P3）。
- 数值处理纪律：区分计量口径（授权额度 / 实际发生额 / 期末余额）、单位归一（万元 / 百万元）、重复披露去重、合计行不计入单笔口径；以上优先由确定性工具完成（P4 MCP 计算器），不靠模型心算。
- 缺证与冲突处理：检索未命中表述为"本次检索未取得该文件"，不推断"未入库"；冲突金额并列给出条件结果，不择一、不取平均；新资料不得静默改写历史结论（C06-C08 的验证点）。
