## 已确认的经验教训

1. **每题独立会话**：题目标签不会自动切换知识库绑定，同会话批量答题必然串味（C05 首轮无效的根因）。
2. **评测题标准答案必须人工复核**，不许 agent 出题 agent 判。
3. 缺证措辞纪律：说"本次检索未取得该文件"，不说"未收录于可检索范围"；未知不写成事实（C05 复核提出的三处收紧）。
