## 过程发现（重要，按优先级）

1. **T07 平台报错**：会话 21 的回答是一条错误信息（"Sandbox user returned an invalid group ID"），属运行环境问题而非模型答错。处理：直接重跑 T07；若复现，按 C07 的诊断路数查工具调度与沙箱配置。
2. **T05 出现记忆跨会话串味**：该会话知识库只绑 041，但 agent 提到"此前分析中曾使用 72,058.45/90,000 这组数字"——这组数字来自 2 分钟前 T03 会话，说明 **Nexent 的记忆功能把跨会话内容带进了隔离会话**。本次未影响结论（agent 正确拒绝使用检索不到的数字），但它破坏了"缺证实验"的隔离前提。处理：正式评测时关闭 agent 记忆（或在无记忆环境复测 T05）；这与 C05 的教训同源，但通道从"同会话上下文"变成了"记忆系统"。
3. **T08 一处越界归因**：agent 把 24,591.86 → 24,564.82 的 27.04 万差额归因为"汇率折算基准不同"。answers.csv 的口径说明明确要求"不得推断余额差异的具体原因"。结论本身正确，但该句超出证据支撑范围，正式评测中会扣口径分。
4. **复制粘贴小瑕疵（无影响）**：会话 18 的题目末尾混入了下一题的标题"## T05 | HG_MISSING"，agent 未受干扰。
5. **判分前提**：answers.csv 未经甲签收。当前 9/10 的通过率是"对未签收答案的预评分"。
