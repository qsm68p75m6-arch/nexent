# A公司担保授权决议 A1

资产标识：D01_authorization_v1

合成测试资料：虚构主体与测试规则。

本文件为合成测试资料。A公司、甲公司、乙公司均为虚构主体；本授权是虚构内部测试规则。

发布日期：2025年12月20日。有效期间：2026年1月1日至2026年6月30日（含首尾日期）。

授权范围：A公司作为担保方，为A公司直接持股比例至少50%的公司提供的外部融资担保。持股比例按查询时点有效的股权资料判断。其他主体的担保不适用本授权，须另查其授权依据。

额度口径：范围内的期末担保余额合计不得超过5,000万元。该上限不是单笔额度，也不是当期新增发生额上限。

计算规则：每个合同只按唯一合同编号计入一次；仅使用同一统计时点的期末余额；统一货币及金额单位后再汇总。汇总行和重复披露不重复相加，不同日期的历史快照不相加。

本测试资料中的所有金额均为人民币。若适用授权、主体关系或金额存在缺失或冲突，应说明限制并请求复核。本文件没有授权根据资料缺失推断现实违法行为。
